Opérateurs de comparaison : `==`, `!=`, `<`, `>`, `<=`, `>=`.

## Code

```csharp
int a = 5, b = 10;
Console.WriteLine(a == b); // False
Console.WriteLine(a != b); // True
Console.WriteLine(a < b);  // True
Console.WriteLine(a > b);  // False
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
False
True
True
False
```
