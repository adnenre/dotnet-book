Les instructions conditionnelles exécutent différents blocs de code en fonction d'expressions booléennes.

## Code

```csharp
int age = 18;
if (age >= 18)
{
    Console.WriteLine("You are an adult.");
}
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
You are an adult.
```
