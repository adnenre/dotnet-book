Les opérateurs effectuent des opérations sur des opérandes.

## Code

```csharp
int a = 10, b = 3;
Console.WriteLine($"a + b = {a + b}");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
a + b = 13
```
