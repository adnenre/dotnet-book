Les boucles répètent un bloc de code plusieurs fois.

## Code

```csharp
for (int i = 0; i < 3; i++)
{
    Console.WriteLine($"Iteration {i}");
}
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
Iteration 0
Iteration 1
Iteration 2
```
