La boucle `for` répète un bloc un nombre spécifié de fois.

## Code

```csharp
for (int i = 1; i <= 5; i++)
{
    Console.Write($"{i} ");
}
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
1 2 3 4 5
```
