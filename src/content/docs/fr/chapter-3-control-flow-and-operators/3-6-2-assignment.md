Opérateurs d'assignation : `=`, `+=`, `-=`, `*=`, `/=`, `%=`.

## Code

```csharp
int num = 10;
num += 5; // équivaut à num = num + 5
Console.WriteLine(num);
num *= 2;
Console.WriteLine(num);
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
15
30
```
