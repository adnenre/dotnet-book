L'instruction `if` exécute un bloc si la condition est vraie.

## Code

```csharp
int temperature = 25;
if (temperature > 20)
{
    Console.WriteLine("It's warm outside.");
}
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
It's warm outside.
```
