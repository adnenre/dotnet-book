L'interface de ligne de commande .NET (CLI) est un outil multiplateforme pour développer, compiler, exécuter et publier des applications .NET.

## Commandes principales

| Commande         | Objectif                             |
| ---------------- | ------------------------------------ |
| `dotnet new`     | Créer un projet à partir d'un modèle |
| `dotnet build`   | Compiler le projet                   |
| `dotnet run`     | Compiler et exécuter                 |
| `dotnet test`    | Exécuter les tests unitaires         |
| `dotnet publish` | Créer une sortie déployable          |

## Structure de commande

```bash
dotnet [commande] [arguments] [options]
```
