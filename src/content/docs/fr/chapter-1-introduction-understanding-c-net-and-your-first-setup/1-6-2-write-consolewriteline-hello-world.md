**Contexte** : `Console.WriteLine()` écrit une ligne dans la console. C'est la méthode de sortie la plus basique dans .NET 10.

```csharp
Console.WriteLine("Bonjour tous le monde");
```

## Interpolation de chaînes

```csharp
string nom = "Alice";
Console.WriteLine($"Bonjour {nom}");
```
