**Contexte** : L'outil de salutation démontre les opérations I/O de base dans .NET 10. L'idée est simple : demander le nom et la couleur préférée, puis afficher une salutation.

## Flux du programme

1. Demander le nom
2. Demander la couleur préférée
3. Afficher une salutation personnalisée

## Exemple d'interaction

```shell
Quel est votre nom ? > Sarah
Quelle est votre couleur préférée ? > Violet

Bonjour Sarah !
Votre couleur préférée, Violet, est magnifique !
```
