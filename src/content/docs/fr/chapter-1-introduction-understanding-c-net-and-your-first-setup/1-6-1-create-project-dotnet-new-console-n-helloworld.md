**Contexte** : Utilisez `dotnet new console` avec le paramètre -n pour créer une nouvelle application console. Le projet cible .NET 10 par défaut.

```bash
dotnet new console -n BonjourMonde
cd BonjourMonde
```

## Programme.cs initial

```csharp
Console.WriteLine("Hello, World!");
```
