**Contexte** : Exécutez l'application Bonjour le monde avec `dotnet run` et observez la sortie. Cela vérifie votre installation .NET 10.

```bash
cd BonjourMonde
dotnet run
```

## Sortie attendue

```bash
Bonjour tous le monde
```
