**Contexte** : Un fake est une implémentation légère et fonctionnelle d'une dépendance qui n'est pas adaptée à la production (ex. une base de données en mémoire). Les fakes ont une vraie logique mais sont simplifiés. Ils sont utilisés lorsque vous avez besoin qu'une dépendance se comporte comme la vraie, mais sans les ressources externes (réseau, disque). Les fakes sont souvent réutilisés dans de nombreux tests.

## Exemple d'utilisation

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using Xunit;

public interface IRepositoryUtilisateur
{
    Utilisateur GetById(int id);
    void Sauvegarder(Utilisateur user);
}

// Implémentation fake (en mémoire)
public class FakeRepositoryUtilisateur : IRepositoryUtilisateur
{
    private readonly Dictionary<int, Utilisateur> _stockage = new();
    private int _prochainId = 1;

    public Utilisateur GetById(int id) => _stockage.GetValueOrDefault(id);

    public void Sauvegarder(Utilisateur user)
    {
        if (user.Id == 0)
        {
            user.Id = _prochainId++;
            _stockage.Add(user.Id, user);
        }
        else
        {
            _stockage[user.Id] = user;
        }
    }
}

public class ServiceUtilisateur
{
    private readonly IRepositoryUtilisateur _repo;
    public ServiceUtilisateur(IRepositoryUtilisateur repo) => _repo = repo;
    public Utilisateur GetUtilisateur(int id) => _repo.GetById(id);
    public void CreerUtilisateur(string nom) => _repo.Sauvegarder(new Utilisateur { Nom = nom });
}

public class ExempleFake
{
    [Fact]
    public void CreerUtilisateur_AjouteAuFakeRepository()
    {
        var fake = new FakeRepositoryUtilisateur();
        var service = new ServiceUtilisateur(fake);
        service.CreerUtilisateur("Alice");
        var user = service.GetUtilisateur(1);
        Assert.Equal("Alice", user.Nom);
    }
}
```

## Remarques importantes

- Les fakes sont plus complexes que les stubs mais plus puissants.
- Ils peuvent être réutilisés dans plusieurs classes de test.
- Les bases de données en mémoire (EF Core `UseInMemoryDatabase`) sont un fake courant.

## Exemple d'utilisation dans le monde réel

**Test d'un panier d'achat** – Utilisez un fake de catalogue produit qui retourne des produits prédéfinis, vous permettant de tester les calculs du panier sans accéder à une vraie base de données.  
Voir [Fake vs Mock vs Stub](https://www.softwaretestinghelp.com/stub-vs-mock/).
