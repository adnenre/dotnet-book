**Contexte** : Le polymorphisme permet de traiter des objets de types différents comme des objets d'un type de base commun. Il rend le code flexible et extensible.

## Deux types

- **Polymorphisme à la compilation** (surcharge)
- **Polymorphisme à l'exécution** (virtual/override)
