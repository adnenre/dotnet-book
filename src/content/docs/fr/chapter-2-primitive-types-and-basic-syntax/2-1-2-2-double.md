`double` est un type à virgule flottante 64 bits avec environ 15 à 17 chiffres de précision. C'est le type par défaut pour les littéraux décimaux.

## Code

```csharp
double pi = 3.14159265358979;
Console.WriteLine($"pi = {pi}");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
pi = 3.14159265358979
```
