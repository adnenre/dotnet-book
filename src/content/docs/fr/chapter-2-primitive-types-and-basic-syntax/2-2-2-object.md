`object` est la classe de base ultime de tous les types dans .NET.

## Code

```csharp
object obj1 = 42;
object obj2 = "Hello";
object obj3 = 3.14;
Console.WriteLine($"{obj1}, {obj2}, {obj3}");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
42, Hello, 3.14
```
