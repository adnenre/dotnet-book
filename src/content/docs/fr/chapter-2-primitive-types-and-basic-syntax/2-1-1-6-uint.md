`uint` est un entier non signé 32 bits. Plage : 0 à 4 294 967 295.

## Code

```csharp
uint min = 0;
uint max = 4294967295;
Console.WriteLine($"uint range: {min} to {max}");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
uint range: 0 to 4294967295
```
