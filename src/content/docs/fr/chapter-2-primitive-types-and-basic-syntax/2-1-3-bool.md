`bool` représente une valeur booléenne : `true` (vrai) ou `false` (faux).

## Code

```csharp
bool isReady = true;
bool isCompleted = false;
Console.WriteLine($"Ready: {isReady}, Completed: {isCompleted}");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
Ready: True, Completed: False
```
