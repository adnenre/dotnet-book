`ushort` est un entier non signé 16 bits. Plage : 0 à 65 535.

## Code

```csharp
ushort min = 0;
ushort max = 65535;
Console.WriteLine($"ushort range: {min} to {max}");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
ushort range: 0 to 65535
```
