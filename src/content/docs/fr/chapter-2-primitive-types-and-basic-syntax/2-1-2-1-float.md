`float` est un type à virgule flottante 32 bits avec environ 6 à 9 chiffres de précision. Utilisez le suffixe `f` ou `F`.

## Code

```csharp
float pi = 3.14159f;
Console.WriteLine($"pi = {pi}");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
pi = 3.14159
```
