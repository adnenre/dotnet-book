Les constantes sont des valeurs immuables connues à la compilation.

## Code

```csharp
const double Pi = 3.14159;
const int DaysInWeek = 7;
Console.WriteLine($"Pi = {Pi}, Days in week = {DaysInWeek}");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
Pi = 3.14159, Days in week = 7
```
