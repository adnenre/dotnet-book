`sbyte` est un entier signé 8 bits. Plage : -128 à 127.

## Code

```csharp
sbyte min = -128;
sbyte max = 127;
Console.WriteLine($"sbyte range: {min} to {max}");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
sbyte range: -128 to 127
```
