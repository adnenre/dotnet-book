`char` est un caractère Unicode 16 bits, placé entre guillemets simples.

## Code

```csharp
char letter = 'A';
char digit = '1';
char symbol = '$';
Console.WriteLine($"Letter: {letter}, Digit: {digit}, Symbol: {symbol}");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
Letter: A, Digit: 1, Symbol: $
```
