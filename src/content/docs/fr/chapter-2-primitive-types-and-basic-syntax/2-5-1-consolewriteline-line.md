`Console.WriteLine` écrit une ligne de texte suivie d'un retour à la ligne.

## Code

```csharp
Console.WriteLine("First line");
Console.WriteLine("Second line");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
First line
Second line
```
