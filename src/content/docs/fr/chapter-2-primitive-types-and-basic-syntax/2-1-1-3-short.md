`short` est un entier signé 16 bits. Plage : -32 768 à 32 767.

## Code

```csharp
short min = -32768;
short max = 32767;
Console.WriteLine($"short range: {min} to {max}");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
short range: -32768 to 32767
```
