`long` est un entier signé 64 bits. Plage : -9 223 372 036 854 775 808 à 9 223 372 036 854 775 807.

## Code

```csharp
long min = -9223372036854775808;
long max = 9223372036854775807;
Console.WriteLine($"long range: {min} to {max}");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
long range: -9223372036854775808 to 9223372036854775807
```
