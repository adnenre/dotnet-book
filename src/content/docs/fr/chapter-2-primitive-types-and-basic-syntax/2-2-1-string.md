`string` est une séquence immuable de caractères.

## Code

```csharp
string greeting = "Hello";
string name = "World";
Console.WriteLine($"{greeting}, {name}!");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
Hello, World!
```
