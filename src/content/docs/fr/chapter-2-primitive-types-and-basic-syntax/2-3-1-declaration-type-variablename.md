Déclarez une variable en spécifiant son type et son nom.

## Code

```csharp
int age;
string name;
bool isActive;
age = 25;
name = "Alice";
isActive = true;
Console.WriteLine($"{name}, {age}, active: {isActive}");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
Alice, 25, active: True
```
