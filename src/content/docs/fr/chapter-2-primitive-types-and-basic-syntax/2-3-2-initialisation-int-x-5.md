Vous pouvez initialiser une variable lors de sa déclaration.

## Code

```csharp
int x = 5;
string message = "Hello";
Console.WriteLine($"x = {x}, message = {message}");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
x = 5, message = Hello
```
