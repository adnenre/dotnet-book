`Console.Write` écrit du texte sans ajouter de retour à la ligne.

## Code

```csharp
Console.Write("Hello ");
Console.Write("World");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
Hello World
```
