Les variables stockent des données modifiables ; les constantes stockent des valeurs fixes.

## Code

```csharp
int variable = 10;
variable = 20;
const double Pi = 3.14159;
Console.WriteLine($"Variable: {variable}, Pi: {Pi}");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
Variable: 20, Pi: 3.14159
```
