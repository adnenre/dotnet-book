Utilisez `$` devant une chaîne et `{expression}` à l'intérieur.

## Code

```csharp
string name = "World";
Console.WriteLine($"Hello {name}");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
Hello World
```
