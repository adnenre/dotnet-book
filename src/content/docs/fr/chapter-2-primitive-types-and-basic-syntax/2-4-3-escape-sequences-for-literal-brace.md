Pour inclure des accolades littérales, doublez-les : `{{` et `}}`.

## Code

```csharp
Console.WriteLine($"{{Hello}}");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
{Hello}
```
