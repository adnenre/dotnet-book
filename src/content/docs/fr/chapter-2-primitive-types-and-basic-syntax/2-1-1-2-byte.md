`byte` est un entier non signé 8 bits. Plage : 0 à 255.

## Code

```csharp
byte min = 0;
byte max = 255;
Console.WriteLine($"byte range: {min} to {max}");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
byte range: 0 to 255
```
