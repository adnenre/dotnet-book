Vous pouvez appliquer des spécificateurs de format à l'intérieur des accolades.

## Code

```csharp
double pi = 3.14159;
Console.WriteLine($"Pi to 2 decimals: {pi:F2}");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
Pi to 2 decimals: 3.14
```
