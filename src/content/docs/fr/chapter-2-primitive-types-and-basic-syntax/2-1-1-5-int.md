`int` est un entier signé 32 bits. Plage : -2 147 483 648 à 2 147 483 647.

## Code

```csharp
int min = -2147483648;
int max = 2147483647;
Console.WriteLine($"int range: {min} to {max}");
```

## Exécution de l'application

```bash
dotnet run
```

## Résultat

```shell
int range: -2147483648 to 2147483647
```
