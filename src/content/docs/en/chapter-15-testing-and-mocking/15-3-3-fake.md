**Context**: A fake is a lightweight, working implementation of a dependency that is not suitable for production (e.g., an in‑memory database). Fakes have real logic but are simplified. They are used when you need a dependency to actually behave like the real thing but without external resources (network, disk). Fakes are often reused across many tests.

## Usage Example

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using Xunit;

public interface IUserRepository
{
    User GetById(int id);
    void Save(User user);
}

// Fake implementation (in‑memory)
public class FakeUserRepository : IUserRepository
{
    private readonly Dictionary<int, User> _store = new();
    private int _nextId = 1;

    public User GetById(int id) => _store.GetValueOrDefault(id);

    public void Save(User user)
    {
        if (user.Id == 0)
        {
            user.Id = _nextId++;
            _store.Add(user.Id, user);
        }
        else
        {
            _store[user.Id] = user;
        }
    }
}

public class UserService
{
    private readonly IUserRepository _repo;
    public UserService(IUserRepository repo) => _repo = repo;
    public User GetUser(int id) => _repo.GetById(id);
    public void CreateUser(string name) => _repo.Save(new User { Name = name });
}

public class FakeExample
{
    [Fact]
    public void CreateUser_AddsToFakeRepository()
    {
        var fake = new FakeUserRepository();
        var service = new UserService(fake);
        service.CreateUser("Alice");
        var user = service.GetUser(1);
        Assert.Equal("Alice", user.Name);
    }
}
```

## Important notes

- Fakes are more complex than stubs but more powerful.
- They can be reused across multiple test classes.
- In‑memory databases (EF Core `UseInMemoryDatabase`) are a common fake.

## Real-world usage example

**Testing a shopping cart** – Use a fake product catalog that returns predefined products, allowing you to test cart calculations without hitting a real database.  
See [Fake vs Mock vs Stub](https://www.softwaretestinghelp.com/stub-vs-mock/).
