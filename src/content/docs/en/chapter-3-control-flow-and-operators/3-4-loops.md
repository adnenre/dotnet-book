Loops repeat a block of code multiple times.

## Code

```csharp
for (int i = 0; i < 3; i++)
{
    Console.WriteLine($"Iteration {i}");
}
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
Iteration 0
Iteration 1
Iteration 2
```
