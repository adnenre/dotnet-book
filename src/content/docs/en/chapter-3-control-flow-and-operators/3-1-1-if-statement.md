The `if` statement executes a block if the condition is true.

## Code

```csharp
int temperature = 25;
if (temperature > 20)
{
    Console.WriteLine("It's warm outside.");
}
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
It's warm outside.
```
