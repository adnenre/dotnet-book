Arithmetic operators: `+`, `-`, `*`, `/`, `%`.

## Code

```csharp
int x = 15, y = 4;
Console.WriteLine($"Sum: {x + y}");
Console.WriteLine($"Difference: {x - y}");
Console.WriteLine($"Product: {x * y}");
Console.WriteLine($"Quotient: {x / y}");
Console.WriteLine($"Remainder: {x % y}");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
Sum: 19
Difference: 11
Product: 60
Quotient: 3
Remainder: 3
```
