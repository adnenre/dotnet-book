Comparison operators: `==`, `!=`, `<`, `>`, `<=`, `>=`.

## Code

```csharp
int a = 5, b = 10;
Console.WriteLine(a == b); // False
Console.WriteLine(a != b); // True
Console.WriteLine(a < b);  // True
Console.WriteLine(a > b);  // False
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
False
True
True
False
```
