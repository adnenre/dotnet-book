Conditional statements execute different code blocks based on boolean expressions.

## Code

```csharp
int age = 18;
if (age >= 18)
{
    Console.WriteLine("You are an adult.");
}
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
You are an adult.
```
