The `else` clause executes when the `if` condition is false.

## Code

```csharp
int age = 16;
if (age >= 18)
Console.WriteLine("Adult");
else
Console.WriteLine("Minor");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
Minor
```
