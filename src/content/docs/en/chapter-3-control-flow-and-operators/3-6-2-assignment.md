Assignment operators: `=`, `+=`, `-=`, `*=`, `/=`, `%=`.

## Code

```csharp
int num = 10;
num += 5; // same as num = num + 5
Console.WriteLine(num);
num *= 2;
Console.WriteLine(num);
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
15
30
```
