`ushort` is a 16‑bit unsigned integer. Range: 0 to 65,535.

## Code

```csharp
ushort min = 0;
ushort max = 65535;
Console.WriteLine($"ushort range: {min} to {max}");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
ushort range: 0 to 65535
```
