sidebar:

  label: 2.4.3 Escape sequences for literal brace
---

To include literal braces, double them: `{{` and `}}`.

## Code

```csharp
Console.WriteLine($"{{Hello}}");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
{Hello}
```
