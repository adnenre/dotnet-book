`double` is a 64‑bit floating point type with about 15–17 digits of precision. It is the default for decimal literals.

## Code

```csharp
double pi = 3.14159265358979;
Console.WriteLine($"pi = {pi}");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
pi = 3.14159265358979
```
