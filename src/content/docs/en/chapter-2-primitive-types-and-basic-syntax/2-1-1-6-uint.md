`uint` is a 32‑bit unsigned integer. Range: 0 to 4,294,967,295.

## Code

```csharp
uint min = 0;
uint max = 4294967295;
Console.WriteLine($"uint range: {min} to {max}");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
uint range: 0 to 4294967295
```
