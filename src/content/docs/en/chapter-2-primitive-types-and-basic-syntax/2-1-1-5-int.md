`int` is a 32‑bit signed integer. Range: -2,147,483,648 to 2,147,483,647.

## Code

```csharp
int min = -2147483648;
int max = 2147483647;
Console.WriteLine($"int range: {min} to {max}");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
int range: -2147483648 to 2147483647
```
