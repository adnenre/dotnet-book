`float` is a 32‑bit floating point type with about 6–9 digits of precision. Use suffix `f` or `F`.

## Code

```csharp
float pi = 3.14159f;
Console.WriteLine($"pi = {pi}");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
pi = 3.14159
```
