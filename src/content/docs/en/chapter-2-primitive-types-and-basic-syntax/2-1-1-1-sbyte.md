`sbyte` is an 8‑bit signed integer. Range: -128 to 127.

## Code

```csharp
sbyte min = -128;
sbyte max = 127;
Console.WriteLine($"sbyte range: {min} to {max}");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
sbyte range: -128 to 127
```
