Constants are immutable values known at compile time.

## Code

```csharp
const double Pi = 3.14159;
const int DaysInWeek = 7;
Console.WriteLine($"Pi = {Pi}, Days in week = {DaysInWeek}");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
Pi = 3.14159, Days in week = 7
```
