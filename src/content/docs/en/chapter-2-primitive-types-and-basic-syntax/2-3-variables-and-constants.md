Variables store data that can change; constants store fixed values.

## Code

```csharp
int variable = 10;
variable = 20;
const double Pi = 3.14159;
Console.WriteLine($"Variable: {variable}, Pi: {Pi}");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
Variable: 20, Pi: 3.14159
```
