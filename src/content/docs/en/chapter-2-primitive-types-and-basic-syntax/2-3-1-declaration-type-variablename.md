Declare a variable by specifying its type and name.

## Code

```csharp
int age;
string name;
bool isActive;
age = 25;
name = "Alice";
isActive = true;
Console.WriteLine($"{name}, {age}, active: {isActive}");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
Alice, 25, active: True
```
