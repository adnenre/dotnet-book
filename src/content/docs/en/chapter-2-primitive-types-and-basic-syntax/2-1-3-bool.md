`bool` represents a Boolean value: `true` or `false`.

## Code

```csharp
bool isReady = true;
bool isCompleted = false;
Console.WriteLine($"Ready: {isReady}, Completed: {isCompleted}");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
Ready: True, Completed: False
```
