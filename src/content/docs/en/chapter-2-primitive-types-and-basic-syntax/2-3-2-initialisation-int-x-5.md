You can initialise a variable at declaration.

## Code

```csharp
int x = 5;
string message = "Hello";
Console.WriteLine($"x = {x}, message = {message}");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
x = 5, message = Hello
```
