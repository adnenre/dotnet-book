`short` is a 16‑bit signed integer. Range: -32,768 to 32,767.

## Code

```csharp
short min = -32768;
short max = 32767;
Console.WriteLine($"short range: {min} to {max}");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
short range: -32768 to 32767
```
