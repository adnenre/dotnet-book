Floating point types represent numbers with fractional parts. They include `float`, `double`, and `decimal`.

## Code

```csharp
float f = 3.14159f;
double d = 3.14159265358979;
decimal m = 123.456789m;
Console.WriteLine($"float: {f}, double: {d}, decimal: {m}");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
float: 3.14159, double: 3.14159265358979, decimal: 123.456789
```
