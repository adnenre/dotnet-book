You can apply format specifiers inside the braces.

## Code

```csharp
double pi = 3.14159;
Console.WriteLine($"Pi to 2 decimals: {pi:F2}");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
Pi to 2 decimals: 3.14
```
