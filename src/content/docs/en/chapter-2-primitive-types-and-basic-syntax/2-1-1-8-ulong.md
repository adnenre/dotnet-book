`ulong` is a 64‑bit unsigned integer. Range: 0 to 18,446,744,073,709,551,615.

## Code

```csharp
ulong min = 0;
ulong max = 18446744073709551615;
Console.WriteLine($"ulong range: {min} to {max}");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
ulong range: 0 to 18446744073709551615
```
