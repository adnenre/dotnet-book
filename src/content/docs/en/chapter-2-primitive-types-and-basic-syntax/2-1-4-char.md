`char` is a 16‑bit Unicode character, enclosed in single quotes.

## Code

```csharp
char letter = 'A';
char digit = '1';
char symbol = '$';
Console.WriteLine($"Letter: {letter}, Digit: {digit}, Symbol: {symbol}");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
Letter: A, Digit: 1, Symbol: $
```
