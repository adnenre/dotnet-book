`string` is an immutable sequence of characters.

## Code

```csharp
string greeting = "Hello";
string name = "World";
Console.WriteLine($"{greeting}, {name}!");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
Hello, World!
```
