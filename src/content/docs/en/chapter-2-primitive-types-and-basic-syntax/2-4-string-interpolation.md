String interpolation embeds expressions inside a string using `$` and `{}`.

## Code

```csharp
string name = "Alice";
int age = 30;
Console.WriteLine($"Name: {name}, Age: {age}");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
Name: Alice, Age: 30
```
