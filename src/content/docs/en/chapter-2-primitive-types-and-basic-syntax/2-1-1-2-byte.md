`byte` is an 8‑bit unsigned integer. Range: 0 to 255.

## Code

```csharp
byte min = 0;
byte max = 255;
Console.WriteLine($"byte range: {min} to {max}");
```

## Run the Application

```bash
dotnet run
```

## Result

```shell
byte range: 0 to 255
```
